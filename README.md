Green Office é um sistema responsivo para o monitoramento de máquinas agrícolas. A aplicação foi desenvolvida com **Next.js**, **Tailwind CSS** e **TypeScript** no frontend, e o backend utiliza **Java Spring Boot**. O sistema inclui autenticação de usuários, uma dashboard completa para gestão de máquinas e várias funcionalidades de filtragem.

## Funcionalidades

- **Autenticação de Usuário**: Tela de login com verificação de autenticação.
- **Dashboard de Máquinas**:
  - Adicionar, editar e deletar máquinas agrícolas.
  - Filtrar máquinas por:
    - Todas as máquinas.
    - ID específico.
- **Responsividade**: Interface totalmente responsiva, adequada para diferentes dispositivos.

## Tecnologias Utilizadas

### Frontend
- [Next.js](https://nextjs.org/) - Framework React para renderização no lado do servidor.
- [Tailwind CSS](https://tailwindcss.com/) - Framework de CSS utilitário para estilização rápida.
- [TypeScript](https://www.typescriptlang.org/) - Superset de JavaScript com tipagem estática.

### Backend
- [Java Spring Boot](https://spring.io/projects/spring-boot) - Framework Java para criação de APIs RESTful.
